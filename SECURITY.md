# Security policy

Coursair runs a small web server on your computer that reads files from the course folders you add. By default it only accepts connections from the same computer (`127.0.0.1`).

## Reporting a problem

Please report security issues privately through [GitHub's security advisories](https://github.com/tanzim12911/coursair-project/security/advisories/new) rather than in a public issue. You should hear back within a week.

Examples of things worth reporting:

- Reading files outside the course folders you added
- A website you visit being able to read or change your Coursair data
- Course files being able to run scripts inside the app
